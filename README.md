# aquaculture-portal

養殖営業向けの海況情報ポータルです。

## v0.1
- 海況トップ
- 地区別水温カード
- 赤潮情報
- 地域トピック（公的情報 + みなと新聞へのリンク）
- FRA-ROMS IIへの予測導線
- 給餌率・給餌サイズ・給餌計算の追加枠

## 方針
取得できない値は推測で埋めず、未接続と表示します。給餌率・給餌サイズは既存Excelを正として後日追加します。
